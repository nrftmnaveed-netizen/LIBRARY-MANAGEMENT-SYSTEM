# Library Management System
Data Structures labs 02-07 (individual project).

| Lab | Data structure | Library use case |
|-----|----------------|------------------|
| Lab02_Stack | Stack | Returned-book pile |
| Lab03_Queue | Queue | Book request management |
| Lab04_PriorityQueue | Priority Queue | Urgent book requests |
| Lab05_SinglyLinkedList | Singly Linked List | Book collection |
| Lab06_CircularLinkedList | Circular Linked List | Featured book display |
| Lab07_DoublyLinkedList | Doubly Linked List | Borrowing session |

Each lab folder has main.cpp, a structure file, a class header, a class member-function file and its own README with compile instructions.
